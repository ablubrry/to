To Do Tasks App
Lists tasks of things to complete.

Node.js needs to be installed before attempting to run vite script on main computer.
In order to bypass error for system permissions use:
Set-ExecutionPolicy -ExecutionPolicy Unrestricted -Scope CurrentUser 
Then run npx create-vite@latest --template react .
Select ESlint as open source, then ignore files and continue.
Run npm install after files are loaded.
Run npm run dev to open the browser.
To close use: Ctrl + C
